# Avance del Informe Final 2.6 - Planify

**Fecha de actualización:** 25/10/2026

## Desarrollo de ingeniería
Planify dispone de una arquitectura cliente-servidor con frontend Angular, API REST en Django REST Framework y PostgreSQL. La versión v0.3 permite consultar lugares y eventos y cuenta con una base de autenticación por token para diferenciar sesiones y roles.

Durante el incremento actual se documentó y comprobó el caso de uso CU06 - Registro de Usuario Persona, vinculando el formulario Angular, las validaciones de backend, la persistencia del usuario/perfil y la salida visible en la interfaz.
