# Evidencia de Aplicación - Planify v0.3

## Arquitectura
Planify utiliza una arquitectura cliente-servidor compuesta por:

- Frontend: Angular.
- Backend: Django REST Framework.
- Base de datos: PostgreSQL.
- Despliegue: Render.

## Funcionalidades comprobadas

- Consulta de lugares.
- Visualización de detalle de lugares.
- Consulta de eventos.
- Registro de Usuario Persona.
- Inicio de sesión.
- Cierre de sesión.
- Autenticación mediante token.
- Persistencia de sesión.
- Perfil de Usuario Persona.
- Base funcional para Usuario Negocio.
- Administración mediante Django Admin.
